# Игра Крестики - нолики

Эта программа предназначена для игры двух участников в крестики-нолики
Программа будет дорабатываться по факту совершенствования компетенций разработчика

Для раскрашивания элементов применяются методы библиотеки **Colorama**:
1) **Fore.Цвет** - цвет шрифта
2) **Back.Цвет** - цвет фона
3) **Style.RESET_ALL** - метод придания яркости и общего сброса установок

# Tic-Tac-Toe Game

This program is designed for two players to play Tic-Tac-Toe.
The program will be refined as the developer’s skills improve.

To color the elements, the following methods from the **Colorama** library are used:
1) **Fore.Color** — font color
2) **Back.Color** — background color
3) **Style.RESET_ALL** — a method for adding brightness and resetting all settings
